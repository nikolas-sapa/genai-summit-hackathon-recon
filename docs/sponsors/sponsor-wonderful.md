## 2. Product: "Wonderful AI OS"

One operating layer connecting goals, context, intelligence, workflows, controls. Four products:

1. **Wonderful Agents** — voice/chat/email/doc agents that engage customers, assist employees, execute end-to-end workflows. Builder features: Workspaces, Versioning, Catalog (reusable agents/skills/tools), Permissions, reusable Skills, **A2A protocol** (agent-to-agent handoffs across platforms), auto-conversation Tags, A/B testing.
2. **Wonderful Systems** — bespoke AI-native business apps that **replace legacy software** (named: CRM, customer value management, knowledge management, HCM). FDE-led rollout, migrates data off the legacy tool. This is the ERP-replacement play — clients use agents to bypass multi-year SAP/Oracle integrations (TBPN).
3. **Wonderful AI Gateway** — control center for ALL enterprise AI traffic: spend tracking, budgets, smart routing by task complexity, failover chains, PII redaction on egress, per-team model permissions, audit logs. (Marketing mock shows gpt-5.3, claude-sonnet-5, glm-5.)
4. **Agent Builder** (launched Jan 23 2026, **built with Anthropic/Claude**) — autonomous "agent that builds agents": ingests policy docs, knowledge bases, call recordings → iteratively builds/tests/refines agents. Claims ~50% faster time-to-production, ~20% fewer early-prod issues. Born from 60+ deployments.

OS primitives listed: Data, Alerts, Permissions, Skills, Orchestrator, CLI, Evals, Guardrails, Workspaces, Knowledge.

**Deployment:** multi-tenant SaaS / single-tenant / BYOC (AWS/Azure/GCP) / air-gapped on-prem. SOC 2 II, ISO 27001, GDPR, PCI DSS, EU AI Act aligned; prompt-injection protection, MCP gateways, zero data retention with model providers, PII redaction, AES-256, pen tests 2×/yr.

**Model-agnostic** — routes per task; Anthropic confirmed as a provider (Agent Builder + ETN interview).

## 3. Business & pricing model (verbatim signals)

- **No billing for professional services/FDEs.** Charges only for **platform consumption + recurring use-case fees** (Winkler, TBPN Sep 6 2026). Deliberately moves agent knowledge in-house — opposite of success-fee BPO.
- Land-and-expand: pick THE right use case → production in weeks (Cosmote 8wk, Piraeus 12wk) → hand keys to customer → next use case. Stated playbook: "Wonderful-led → full client ownership, by design."
- Delivery model = **Palantir-style pods**: local GM + Deployment Strategists + Forward Deployed Engineers embedded onsite; "guilds" per profession control hiring quality. Winkler: delivery-heavy only works with enormous TAM + core-to-enterprise work.
- GTM alliances: **McKinsey partnership** (Apr 2026, strategy-to-scale), hyperscaler partner marketing role (AWS/Azure/GCP marketplace motion), system integrators, FC Bayern "Official Enterprise AI Partner". Public-sector GTM roles exist.

## 10. Predicted challenge brief (ranked)

Their DNA = **end-to-end execution in messy, regulated, non-English enterprise environments, measured in production metrics.** Expect briefs written by FDEs, not marketers:

1. **(Most likely) Full-journey voice/omnichannel agent for a Greek enterprise workflow** — e.g. telecom troubleshooting or bank/utility call flow: authenticate caller → diagnose → take ACTION in a provided mock system via tools/MCP → confirm → log. Bonus: graceful human handoff + Greek language fluency. This IS their OTE/Piraeus playbook in miniature.
2. **Agent that executes a multi-step back-office process across ≥2 systems that don't talk to each other** (their "legacy bridge" ERP-bypass thesis): read request from email/chat → pull data from system A → write to system B → handle edge cases → produce audit trail.
3. **A2A / multi-agent orchestration:** several specialized agents handing work to each other with permissions and an auditable trail (maps to their Orchestrator + A2A + governance primitives).
4. **Evals/quality-loop tooling** (their admitted gap per Technical PM JD): monitor agent runs, detect regressions/failures, diagnose, propose fixes — "production-grade, not a demo."
5. **Employee copilot grounded in org knowledge with enforced permissions** (Skills + Knowledge + Permissions primitives).
6. Wildcard: **proactive agent** (their theme word: "proactively") — watches a queue/stream and initiates work unprompted, e.g. collections outreach, shipment exception handling, appointment rebooking. Shipping/logistics flavor plausible given stated expansion targets.

Judging will overweight: did it DO real work end-to-end (tool calls landed, state changed), measurable outcome, enterprise-grade thinking (guardrails, PII, handoff), Greek/localization nuance = bonus aura.

## 11. The demo that gets a job offer / term sheet

**Build:** a **Greek-language voice agent that owns one complete, painful workflow end-to-end** — e.g. "ELTA parcel exception resolver" or "telco fault-triage agent":
- Real phone/voice interface (Twilio/LiveKit/Vapi — they prize voice heritage)
- Caller auth + PII redaction → diagnosis against a knowledge base → **write actions into a mocked legacy system via MCP tool calls** (ticket creation, package re-delivery booking, billing adjustment) → SMS/email confirmation → human escalation path with context transfer
- Live dashboard: containment rate, handle time, tool-call success — **speak in THEIR metrics** (containment, AHT, weeks-to-production)
- Model-agnostic routing + one failover (their AI Gateway pattern), a visible guardrail (injection attempt demoed and blocked = aura points)
- Ship an **eval suite + runbook** with the repo = their "hand the keys to the client" doctrine; frame it "what an FDE would hand over at end of a 36-hour deployment"
- Tell the story their way: "discovery → production → measurable impact → handover." Name-drop nothing; demonstrate everything.

**Why it lands:** it's a compressed FDE deployment. Hiring + M&A is the reason they sponsor — they're doubling the Athens office (all Greece roles open now) and hunting Greek acquisitions. A team that demos a working Greek enterprise agent IS their acquisition/hiring filter. Big Pi is also in the partner list → term sheets possible.

## 12. Do NOT build

- ❌ A generic agent-builder / orchestration / "AI OS" platform — that IS Wonderful's product; you'd be pitching a competitor to its own sponsor.
- ❌ An AI gateway/router/evals-PLATFORM as the whole product (their AI Gateway + Agent Builder own this; a quality-loop *tool* used inside your build is fine, a platform is not).
- ❌ English-only, US-market chatbot with no tool execution — antithetical to everything they stand for (non-English-first, end-to-end execution).
- ❌ Thin LLM wrapper, no real action taken, no metrics — "demo, not a job" is the stated anti-pattern.
- ❌ Success-fee / BPO-style business framing — Winkler explicitly rejects it; consumption+platform is the doctrine.
- ❌ Mid-market/SMB positioning — they only serve >$750M-revenue orgs; frame target as large enterprise.
