## 5. treg — https://treg.to
- **What:** "OpenRouter for agent tools" — one API key → 4,100+ endpoints across ~126 providers (SEO, leads, ads, social, scraping, enrichment); pay-per-call, 0% markup, BYOK; AGPL open source, self-hostable.
- **HQ:** Founder based in Australia; remote/tiny (2 people). Launched 2026.
- **Key people:** Jason Zhou (founder); Shi Tianxin (founding engineer). Prior pivot: SuperDesign (design agent, 6,000+ GitHub stars), then a growth agent, then treg — 3 pivots in 9 months.
- **Funding:** Not disclosed; Product Hunt launch ~3 months ago (#7 day rank). ~140k monthly site visits. Notable: published a security incident report 23 Oct 2026.
- **What would excite them:** Agents that actually procure and call external tools/data mid-task — their entire thesis is "agents buy tools per-call." A project whose agent searches treg's catalog, picks a provider on price/success-rate, and completes real work is a live validation of their product.
- **Angle/quirk:** Sponsor credits likely available; wiring treg in as your agent's tool layer = free points with a sponsor judge. Also: they benchmark vendors live — a "vendor-picking" agent demo flatters their model.

## 6. boxd — https://boxd.sh
- **What:** "Composable computers" — persistent, hardware-isolated Linux VMs for devs and agents; <10ms boot, <200ms live-fork (state + memory + disk), snapshots/checkpoints/hibernate, per-machine HTTPS URL; self-hostable KVM binary; EU-hosted.
- **HQ:** Amsterdam (Westerstraat 246); fka "Azin" — Dutch/Romanian founding roots. ~9 people across NL/DE/UK. Founded 2025–26.
- **Key people:** Hidde Kehrer (co-founder, public face), Laurentiu Ciobanu (co-founder/CTO), Michiel Voortman (co-founder/CPO); Nordic9 also lists Savian Boroanca; build team Stefan Ghegoiu, Alexandru Jonny Şerban.
- **Funding:** €2M pre-seed (Sep 2026) led by BlueYard Capital; Antler, OVNI, s20, Script Capital + angels.
- **Thesis:** "Kill localhost" — coding agents need real, persistent, parallel machines, not containers that lose state. "Agents will need billions of machines."
- **Hiring:** Small team (~6→9), "expanding."
- **What would excite them:** Multi-agent parallelism — N agents each on their own boxd VM, forking environments mid-run; sandboxed execution of untrusted agent code; preview-env-per-PR workflows.
- **Angle/quirk:** **They launched at a hackathon** ~Apr 2026 (Kehrer's own LinkedIn) — they love hackathon-native stories. Run your whole build/demo on boxd VMs and name-drop it.
