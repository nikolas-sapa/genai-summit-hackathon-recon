## 5. ΜΕΤΑΒΙΒΑΣΗ — REALITY CHECK vs the doc-chase concept

**The state's own plumbing:** «Ηλεκτρονικός Φάκελος Μεταβίβασης Ακινήτων» @ **akinita.gov.gr** (Hellenic Cadastre, N.4821/2021 art.29, live early-2024). Notary opens file, invites parties via email+SMS (Εθνικό Μητρώο Επικοινωνίας), parties auth via Taxisnet, notary = "one-stop shop" collecting the **9 δικαιολογητικά** + files the act for cadastral registration. **Adoption <1% of transfers** (World Bank Subnational B-READY 2024 cite); notary guild strikes (αποχή Jan 2025, ψηφιακό αντίγραφο dispute); platform teething bugs; Kyuranakis (DepMin) doing weekly notary-assoc meetings to debug.

**Core document set (seller-side, verified vs michanikosapps/homi/notary guides):**
1. Τίτλοι/συμβόλαια chain (lawyer title check, 20-yr lookback, mortgages/liens at Υποθηκοφυλακείο or Κτηματολόγιο — **dual regime by area**)
2. **ΗΤΚ** (Ηλεκτρονική Ταυτότητα Κτιρίου) or Πιστοποιητικό Πληρότητας — engineer-prepared: topographic (ΚΑΕΚ), ν.4495/4014 αυθαίρετα declarations, plans; mandatory for the act
3. ΠΕΑ energy cert (engineer)
4. Πιστοποιητικό **ΕΝΦΙΑ** — requires 5 yrs of consistent E9s; mismatches → E9 corrections → αντικειμενική αξία recalcs → ENFIA/ΤΑΠ recomputation cascade
5. Βεβαίωση μη οφειλής **ΤΑΠ** (municipality — manual, speed varies by δήμος)
6. Φορολογική ενημερότητα (tax clearance — validity-window doc)
7. Ασφαλιστική ενημερότητα (EFKA — if seller is self-employed/company member)
8. ΦΜΑ 3% declaration via **myPROPERTY (AADE)** — or first-home exemption pack (extra docs)
9. Conditional extras by zone: Δασικοί χάρτες/forest declarations, ΑΓΔ cert for border zones (Golden-Visa buyers hit this), δήμος fees, κοινοχρήστων
Then: προσύμφωνο/deposit → συμβόλαιο at notary → registration (Κτηματολόγιο where live, else Υποθηκοφυλακείο) — the last mile has the worst variance.

**Bottlenecks (hard numbers, World Bank B-READY via workenter.gr):** full transfer ≈ **56d** Alexandroupoli/Patra, 122d Heraklion, **136d Athens**, 142d Larissa, **213d Thessaloniki**; registration step alone 5d vs **195d** (Alexandroupoli vs Thessaloniki); "hundreds of thousands" of acts pending in title-check/registration; up to 7 months anecdotal. Causes: υποθηκοφυλακείο→κτηματολόγιο transition lag, pending-κτηματογράφηση zones, notary capacity, municipal TAP manual-ness, E9 mismatches, multi-actor ping-pong (seller, buyer, lawyer, notary, engineer, bank, δήμος, εφορία, cadastre).

**Concept verdict:** ✅ enumerable doc set (~9 + conditionals) ✅ chase-able actors ✅ clock semantics (validity windows, 60d/90d promises) ✅ their literal ops (Prosperty sells "transfer coordination" today — iauction post-award service and Offera stage-4 both = human doc-chase) ✅ Eurobank batch-transfer pain (2,000 REOs each needing the same file). ⚠️ **Access reality:** none of these systems offer citizen/agent APIs — akinita is notary-gated (Taxisnet+notary-registry creds), TAXISnet delegation runs through πληρεξούσιο, municipal TAP is email/phone, Υποθηκοφυλακείο is paper. **So the build = orchestration copilot, not a scraping agent:** transfer-file state machine (9-doc checklist per case), outbound chase automation (email/WhatsApp drafts+send on approval), inbound doc receipt+classification (light — full extraction is their Gold-award turf; keep it "is this the right doc, signed, in-date?" verification not content extraction), dependency/SLA clock (ENFIA cert ↔ E9, ΗΤΚ ↔ engineer visit, TAP ↔ δήμος), exception flags (αυθαίρετα, liens, name/ΑΦΜ mismatch), notary-ready file + signed action log. Instrument "days-to-transfer" vs their 60-day-sale/90-day-transfer marketing — measurable before/after.
**Demo fixture (36h-realistic):** 1 synthetic Eurobank-REO file, 3 stuck docs (ΤΑΠ pending δήμος 14d, ENFIA blocked by E9 mismatch, ΗΤΚ missing engineer sign-off) → agent detects dependency, drafts Greek chase emails, fires one on approval, re-verifies, prints notary-ready index + audit log. Real names of real systems = the aura.
