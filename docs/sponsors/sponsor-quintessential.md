## 11. What impresses a Quintessential judge — decoded

**Win signals (their own vocabulary):**
- Agent **does real work end-to-end** in the demo — not a narrator, not a mock. Multi-step, goal→plan→tools→verified output.
- **Guardrails by construction**: scoped tool allowlist, least-privilege creds, human-approval gate on irreversible actions, audit trail. Even a toy version (permission tiers, dry-run/plan-vs-apply, "the agent proposes, a human merges") maps 1:1 onto their published doctrine.
- **"Maker visible in the work"**: deliberate choices you can defend — why this tool call, why this rejection. Be ready to answer "what did the human decide?"
- **Knowing when the model bluffs**: evals, sanity checks, verification loop in the agent itself; admitting and handling failure modes beats flawless theater.
- **Craft = the last mile**: error states, empty states, retries, timeouts, the ugly edge case handled. "Nobody needed this — that's why it matters" micro-polish (one memorable detail > ten half-features).
- **Honest engineering**: real repo hygiene, typed contracts between components, reuse (Conduit/skills/MCP) over bespoke slop; monorepo-with-shared-types sensibility.
- **Side-project energy / aura**: weird, joyful, personal; "a tiny game, a weird tool, built for the sake of it."
- Usefulness grounded in a real workflow (agency ops, banking-adjacent, DevOps, healthcare admin, Greek-market pain) resonates more than generic chat-with-X.

**Lose signals:**
- Slop: prompt-twice-ship-it UI, stock Vercel-gradient look, no opinion in the work.
- Vibe-coded demo: can't explain what the code does; falls over on the second input.
- Chatbot-in-a-trench-coat: "agent" that's one LLM call with no tools, no state, no verification.
- Deck-first teams; pre-built projects (they weigh what's made in the 36h window).
- Over-privileged demo ("the agent just has my root token lol") — to this team it's not naive, it's *the threat model*.

## 12. Tactical notes for a winning submission aimed at them

- Architect like their doctrine even in miniature: agent identity → scoped tools → plan/diff → human gate → logged actions. Mention it in the demo; it's their literal blog post.
- Demo the **ugly path**: a failure caught, retried, escalated for approval. Their canon says trust is built there.
- One signature craft detail (haptics/squircle-equivalent for your domain) + boring fundamentals handled. That's their BeWell formula verbatim.
- If you can make your artifact agent-consumable (skills file, MCP tool, clean structured API) you're speaking their newest dialect.
- Name-drop nothing; show everything. Their posture: "not a pitching competition — an agent at work."
