## 5. STRATEGIC ASSESSMENT — using Devin/Windsurf visibly

**Would judges know/care?** Split answer:
- **Organizers (Abed, 100mentors/Yiorgos, Panathēnea) — YES, enormously.** Your team visibly shipping with Devin is live validation of the exact pitch Abed is trying to close. You become the demo case in the post-event report Cognition's growth team reads ("N of 120 builders onboarded to Devin, X merged PRs"). That report IS the conversion artifact for a pending deal.
- **Sponsor/judge panel — mostly no, unless deal closes.** If closed, Cognition rep(s) on the panel will reward it directly (their own brief + own judge per Challenge terms). If pending, Koukoumidis-type judges care about whether the *artifact* works, not what built it — BUT "Devin built this" wins aura points with Abed's indie-builder archetype and costs nothing.
- **Risk asymmetric:** headline reliance on a *competing* coding agent (Cursor/Claude Code/CC) is the one move that could sting — it undermines the exclusivity ask mid-negotiation. Using Devin/Windsurf is zero-cost upside.

**Maximum-effect playbook:**
1. **Onboard to Devin BEFORE day 1** (free tier / Devin for Startups $15K credits application — approval is rolling, apply now). Arrive with an active account; if Cognition closed the deal, take on-site seats anyway and say so.
2. **Delegate real tickets, not autocomplete.** The Cognition-internal dogma (and Erasmo's workshop doctrine, verbatim from Nerdearla): "delegate whole tasks → Devin investigates, plans, implements, runs tests, delivers a PR → human reviews." Run the build as parallel Devin sessions on well-scoped tickets; humans act as architects/reviewers. Have merged-PR receipts to show.
3. **Use Devin Review on your diffs** and mention it. Receipts: "Devin opened 11 PRs, Devin Review flagged 3 issues, we merged 9."
4. **One line in the pitch, not the pitch:** "This agent was substantially built BY an agent — we orchestrated Devin sessions in Windsurf while it wrote and tested the code." Meta-aligns with "Agents at Work" (their own tagline) without making tooling the story — Koukoumidis still judges the artifact.
5. **Quantify leverage:** sessions run, wall-clock saved, PRs merged overnight ("ran 37× overnight" style metrics are literally Cognition's marketing language — Modal customer quote: "37 Devin sessions in one day, ~20 eng-months saved").
6. **Day-1 social move:** if any Cognition rep/ambassador is at a mentor table (watch for Erasmo or a Psorakis-org field engineer — EMEA team is London-based, Athens is 3.5h direct), show them working receipts and ask what brief they'd sponsor. If deal closed, ask for the challenge brief FIRST.
7. **What converts the deal:** post-event report metrics. Every team visibly using Devin = usage numbers Cognition can justify internally. Your demo on the SNFCC stage saying "built with Devin" in front of 5,000 = the stage proof-point their EMEA growth case needs. You are not just using their tool — you're manufacturing their EMEA case study.

**Exploit-stack angle:** Devin as the build harness composes with everything else (Firecrawl ingest → Oumi SLM → fal output inside a repo Devin works on). "Our codebase was worked on by Devin while our product is an agent" = two layers of agentic alignment.
