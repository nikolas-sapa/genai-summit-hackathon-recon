## 7. GAPS IN THE FIELD (white space)

1. **Agent-infra/eval depth is scarce.** Only Mavrikos, Zidago, Sigurðsson (and Porios) have systems credibility. A working eval loop or verifiable-action trail beats 90% of the room on "craft".
2. **Voice agents = open lane.** The one person with a production voice agent (Tsolakidis) is mentoring, not competing. Live phone-call demo = aura gold, unclaimed.
3. **Personal/proactive agents** = the org's own hinted taste (Muse/Instinct/Dots/Grok Bot refs) — few will read that signal; most will default to enterprise-doc bots.
4. **Enterprise doc/inbox agents will be CROWDED** — every student team + sponsor-brief followers converge there (Prosperty, Wonderful, AUEB winners' whole playbook). Win it only with real-system execution, not the idea itself.
5. **Gov/bureaucracy agent** = Porios's home turf; open only if he mentors instead of competing. Watch his badge.
6. **Crypto/agent-payments/agent-OS** = Zindros bait + SuiHub crowd (Hoxha's Sophon) — niche, high-variance; someone from that scene probably attempts it.
7. **Hardware/physical agents** = nearly empty (Pantazis the only visible embedded profile; Ion likes "physical AI" but he's organizing).
8. **The aura war:** creators (Leonardou, Zafeiri, Karypis, Michail) own stagecraft — beat them on live technical proof, don't try to out-present. Judges are builders; a genuinely working end-to-end run is the one thing their squads can't fake.
9. **Recruiting subtext:** Wonderful (hiring Athens), NOFire, Crowdcruit, Quintessential all scout here — rivals have dual motive (prize + job), expect max effort from sponsor-adjacent engineers.
