## What the pair signals collectively

- Organizers want **OpenAI proximity on both axes**: research credibility (Pittarokoili: frontier-model data/evals) + talent/recruiting legitimacy (Chatziathanasiadou: 9-yr OpenAI people-ops insider). The hackathon is implicitly a **talent funnel** — perform well and you're in a room with the person who built OpenAI's research-recruiting machine.
- Both are **Greek-diaspora returnees** (AUEB→Stanford; Greek family→Berkeley/SF) — the summit's whole thesis is "trust infrastructure" built by Greeks who made it inside frontier labs.
- Judging-room complement: **Pittarokoili scores the "does it work / prove it" axis; Chatziathanasiadou scores the "who built it / can anyone use it" axis.** A project that wins both = a working agent with a measured outcome AND a legible, human-centered demo by a well-functioning team.
