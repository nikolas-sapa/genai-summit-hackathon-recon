## 5. FAiE + BYOH + GRPO (Nov 4 launch) — what a day-one project looks like

### The features (all live or preview as of Nov 4/5)
- **FAiE (Frontier AI Engineer)**: chat agent inside platform.oumi.ai — you describe the goal; it designs evals, finds failure modes, synthesizes/curates data, picks model+strategy, runs training experiments, deploys, monitors. Approval gates on billable actions; `Auto-approve` toggle; `@`-mention datasets/evaluators/models. Cannot upload files or touch billing. Agent tokens $6.25/$31.25 per 1M in/out.
- **BYOH (Bring Your Own Harness)**: register YOUR agent's public HTTPS endpoint → Oumi runs evals + simulated users against your runtime. Protocol v1 = 4 routes (`POST /submit`, `GET /get_status`, `GET /collect_output`, `POST /cancel`), OpenAI-format messages w/ tool_calls; model-under-test via `https://inference.oumi.ai/v1` scoped key; 30s/15min limits; `input_required` for simulated-user turns. Your prompts/tools/memory never leave your stack.
- **Agent dev platform**: define tools (JSON schema) + tool impls (your endpoint | ask-user | fixed | LLM-simulated) + simulated users w/ personas → bulk multi-turn tool-use conversations → SFT on best traces.
- **Post-training**: SFT + **DPO (GA)** + **GRPO (private preview on platform)**, multi-stage training, on-policy distillation. Platform SFT ≤16B = $0.49/1M tokens.
- **OSS already has GRPO live** (bypass the preview): verl integration since v0.9 — train on tool-calling data, execute tool calls against REAL environments (DBs, HTTP endpoints, deterministic lookups, model-simulated), synthesize multi-turn tool convos, **GRPO/RL over any of those environments**. Configs: `configs/examples/grpo_verl_{gsm8k,medqa,countdown,geometry3k}`, `grpo_tldr`, `letter_counting/grpo`, `recipes/vision/molmo/grpo`. **Nov 9: multi-reward summation under VERL_GRPO (#2735) — Androna's commit, 5 days before kickoff.**

### The day-one-adopter project shape (what judges haven't seen anyone do yet)
1. Build your agent harness → expose it as a **BYOH endpoint** (ngrok/cloudflared, 4 routes, ~200 lines)
2. Run **Oumi agent evals w/ simulated users** → collect real failure traces on YOUR task
3. Failures → **synth training data** (FAiE or `oumi synth`) → **SFT a sub-10B SLM**, then **DPO or GRPO on task-success reward** (multi-reward: correctness + format + tool-validity = the Nov-9 feature)
4. Close loop: re-eval via BYOH, show **before/after numbers + Banking77-style table** (your SLM vs GPT-5.x: acc, p50 lat, $/1k)
5. Narrate it in their language: "production failures → eval set → training data → owned weights" = FAiE's exact sales loop, done manually in 36h
6. Stretch aura: `weights-lab` live weight-edit, or a **Krikri-8B** fine-tune for the Greek-vertical subtask (zero competition, Manos's narrative)

Nobody at Nebius/Eclipse could do this — features didn't exist. First mover gets the "they ran our Nov-4 launch end-to-end" story.
