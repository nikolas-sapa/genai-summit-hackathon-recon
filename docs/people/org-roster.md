## CROSS-CUTTING READ
- The bloc splits cleanly: engineers (Zeibekis, Kaparounakis, Pastas, Maltezakis) want plumbing + numbers; narrative/impact (Miliaresis, Sarilakis, Efstathiou, Marinaki) want framing + meaning + taste; research/domain (Kapsiani, Kriezis, Katsikis, Charalampopoulou, Tzirides, Paziotopoulou) want rigor in their own discipline's currency (evals, field data, KPIs, usability evidence, legal hygiene).
- Universal winner across all 14: a working end-to-end agent doing tedious multi-step work for a named user, with one honest metric and zero slop — the summit's own stated bar.
